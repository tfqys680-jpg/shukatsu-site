導入文
車を手放すことは、持ち物の整理であると同時に、これからの暮らし方を考える機会です。「高く買い取ってくれるから」と急いで決めず、契約の条件と、手放した後の生活を分けて確認しましょう。
この記事では、公的な注意喚起を踏まえた契約上の確認点と、本人・家族が使える独自の準備メモを紹介します。車の売却を一律に勧めるものではありません。

H2：中古車売却について新たな注意喚起【ニュースの事実】
H3：電話での了承と、引き渡し後の条件変更が問題に
国民生活センターは2026年11月5日、「中古車売却時のトラブルに注意」を公表しました。80歳代の人が電話で売却額を了承した後にキャンセル料を求められた事例や、不具合を申告した60歳代の人が引き渡し後に減額等を求められた事例を紹介しています。相談・契約の具体的な年月日は公表本文に記載されていません。[1]

H3：新しい制度ではなく、取引前の確認を促す情報
今回の発表は法改正の案内ではありません。個々の事例から、すべての契約の有効性やキャンセル料を判断することもできません。

H2：査定額を聞く前に「今日すること」を決める【一般的な解説・独自提案】
H3：査定の場で契約を急がない
消費者庁は、査定の場では契約せず、事前に契約書を確認するよう案内しています。[2]
家族で同行するときは「今日は査定額と条件を確認する日」と本人と共有しておく方法があります。業者にも検討段階であることを伝え、分からない説明を残したまま了承しないようにします。これは本記事の提案です。

H3：家族の都合だけで売却を進めない
本人は何のために車を使っているでしょうか。通院、買い物、趣味、知人との交流など、車が支えてきた生活を書き出してみます。
家族が「もう不要」と決めるのではなく、本人が続けたい暮らしと、代わりの移動方法を一緒に検討しましょう。運転の適否をこの記事から判断することはできません。

H2：契約書で確認する3つのまとまり【一般的な解説】
H3：売却額と、取り消したい場合の条件
車の売却は特定商取引法によるクーリング・オフの対象外と国民生活センターが案内しています。「あとで無条件にやめられる」と考えず、キャンセル料の額・発生時点、契約上の解除条件を確認します。[3]
クーリング・オフがないことと、どのような場合も争えないことは同じではありません。契約内容や勧誘の経緯について疑問があれば、専門の窓口へ相談してください。

H3：入金と、車・書類の引き渡し
国民生活センターは支払条件の確認を促しています。[3] 入金予定日と引き渡し予定日を別々に書き、遅れた場合の連絡先も確認しましょう。本人が説明を理解できる形で控えを残すことを勧めます。

H3：車の状態を伝えた記録
修復歴・事故歴・冠水歴など、把握している情報は査定前に適切に伝えます。申告済みの修復歴等について、査定・契約後にそれを理由とする減額や解除を求められた場合、応じる必要はないと国民生活センターは説明しています。[1]
一方、すべての減額要求を一律に無効と判断することは避け、申告内容、契約、相手の説明をそろえて相談します。

H2：終活ノートに残す「車を手放す前の確認表」【独自提案】
H3：金額だけでなく暮らしも比べる
次の表は本記事の編集上の提案です。公的機関の指定様式や、手続きの網羅的な一覧ではありません。

| 確認すること | メモする内容 |
|---|---|
| 本人の希望 | 手放す理由、まだ迷っていること |
| 売却後の暮らし | 通院・買い物・趣味の移動方法と費用 |
| 契約者・名義 | 車検証等で確認する事項、手続き先に聞くこと |
| 価格・条件 | 提示額、費用、変更条件、説明を受けた日 |
| キャンセル | 発生条件、金額、申し出先 |
| 入金・引き渡し | それぞれの予定日と連絡先 |
| 車の状態 | 申告した内容、記録の保管場所 |
| 困った場合 | 家族等の相談相手、消費生活相談窓口 |

H3：秘密情報は一覧へ書き込まない
共有メモには暗証番号・パスワードを記載せず、資料の保管場所を中心に残します。名義人が亡くなっている、所有者が販売会社等になっているなど、手続きが分からない場合は、必要な手続きと権限を確認してから進めます。家族であることだけを理由に、本人に代わって契約できると判断しないでください。

要点チェックリスト
□ 本人の希望と売却後の移動方法を話した
□ 査定を受けることと売却の了承を分けて考えた
□ 契約書と説明の不明点を解消した
□ キャンセル料の条件・金額・発生時点を確認した
□ 入金日と車・書類の引き渡し日を別々に記録した
□ 把握している事故歴等を伝え、記録した
□ 契約や相談の控えを保管した

よくある質問
Q1：自宅へ来てもらった買取でもクーリング・オフできますか？
車の売却は、特定商取引法のクーリング・オフの対象外です。訪問買取だから一律に使えるとは考えず、契約前に解除条件を確認してください。[3]

Q2：電話で「お願いします」と言っただけなら、契約していませんか？
書面に署名していないことだけで結論を出さず、どんな説明を受けて何に了承したかを整理して相談してください。今回の注意喚起にも電話での了承後の相談例があります。[1]

Q3：相談はどこへすればよいですか？
消費者ホットライン188や、JPUC車売却消費者相談室が案内されています。JPUCは0120-93-4595、平日9～17時です。解決や返金が保証されるわけではありません。[2]

公開前に人が確認すべき事項
法務：クーリング・オフの適用除外、口頭での契約成立、解除・キャンセル料、減額要求の条件を専門家が確認。名義・相続・代理権限は個別判断であることを保持する。
医療：高齢であるだけで認知症や運転能力低下を推測しない。運転を続けるかの医学的判断を記事で行わない。
税務：売却益、自動車税等の扱いや還付を一律に説明しない。追記する場合は車の用途・登録状況等と最新資料を専門家へ照合する。
編集：相談例の日付を公表日から推定しない。出典の対象条件を省略しない。電話番号・受付時間、既存記事との重複を確認する。
