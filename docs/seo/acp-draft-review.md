## 人手確認の対象（作成時）

医療職レビューは2026-10-22の運営者報告により完了として扱う。以下は下書き時の確認対象であり、医療職レビューを未了へ戻すものではない。担当者・指摘内容は運営者保管の記録に従い、推測して追記しない。法律部分のレビューは将来推奨・未実施のまま。

| 別 | 該当箇所 | 理由 |
|---|---|---|
| 医療 | 「医療についての今の考え」、話し合いの進め方 | 個別の病状や治療選択への助言と読まれないか、掲載前に表現を確認するため |
| 医療 | 「代わりに意思を伝えてほしい人」、FAQ第3問 | 本人の意思を伝える役割と、医療同意を行う権限を混同させないため |
| 医療 | 比較表の「医療同意書」 | 根拠は手術同意の説明であり、すべての医療行為・書類に一律に当てはめないため |
| 法律 | ACPのメモと各書類の比較表 | 一般的な目的の比較にとどまり、個別の有効性・代理権を判断していないことを確認するため |
| 法律 | 遺言書・任意後見契約の説明 | 公開時点の制度との整合性と、専門家・公的窓口への案内を確認するため |
| 介護制度 | 「介護についての希望」、相談先 | サービスの利用条件・費用・相談範囲は個別確認が必要なため |
| 介護制度 | 2027年度介護報酬改定への言及 | 公開までに議論が進む可能性があり、検討段階の発言を決定事項として扱っていないか確認するため |
| 個人情報 | 医療機関情報、連絡先、記録の保管・共有 | 本人と連絡先を載せる相手の意向、共有範囲、保管方法を個別に確認するため |
